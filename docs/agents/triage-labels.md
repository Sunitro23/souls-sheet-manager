# Triage labels

| Rôle canonique | Label GitHub | Sens |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | À évaluer par un mainteneur |
| `needs-info` | `needs-info` | Informations attendues du demandeur |
| `ready-for-agent` | `ready-for-agent` | Spécification prête pour un agent autonome |
| `ready-for-human` | `ready-for-human` | Réalisation humaine nécessaire |
| `wontfix` | `wontfix` | Ne sera pas traité |

Quand un skill mentionne un rôle, utiliser le label correspondant. Modifier la colonne Label GitHub pour adapter ce vocabulaire.
